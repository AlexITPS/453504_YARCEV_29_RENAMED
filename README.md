# Описание лабораторных работ по ИГИ (Избранный главы информатики)

Примечание: описание по STRWEB пропущено (будет представлено в следующем семестре).

IGI_LR1 - Работа с Git: простые примеры и упражнения для отработки базовых операций в системе контроля версий - инициализация репозитория, создание и переключение веток, коммиты и разрешение конфликтов.

IGI_LR2 - Работа с Docker: материалы по контейнеризации приложения, включая Dockerfile, примеры запуска контейнера и отчёт с описанием проделанной работы.

IGI_LR3 - Python (часть 1): учебные задания и скрипты на Python для численных и практических задач; пример - интерактивная программа для вычисления степенного ряда ln(1-x) с модульной структурой.

IGI_LR4 - Python (часть 2): набор задач по анализу данных и разработке модульных Python-приложений. В этой ветке есть несколько заданий (Task1-Task6), модули для моделей и хранения данных - это означает, что лабораторные включают загрузку и предобработку данных с помощью файлов, реализацию логики моделей и сохранение/чтение результатов.

IGI_LR5 - Django: полноценный пример веб-приложения на Django с несколькими приложениями (analytics, repairs, repairstudio, users, website), конфигурацией для контейнеризации (Dockerfile, docker-compose.yml), тестами и локальной БД (db.sqlite3). В ветке есть manage.py, requirements.txt, шаблоны и структуры приложений - это рабочая демонстрация создания CRUD-интерфейсов, маршрутизации и тестирования в Django, готовая для локального запуска или контейнеризации.

Чтобы посмотреть полный код и все файлы каждой лабораторной, переключайтесь на соответствующую ветку: в GitHub выберите нужную ветку (например, IGI_LR4 или IGI_LR5) или локально выполните git fetch && git checkout <branch-name>. В ветках вы найдёте все скрипты, модули, Docker-конфиги и отчёты по выполнению каждой из работ.
